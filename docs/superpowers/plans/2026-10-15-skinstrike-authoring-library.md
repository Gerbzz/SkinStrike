# SkinStrike authoring and library implementation plan

1. **Paint model:** Add `PaintStroke` and `LayerContent::Paint` in `src/document.rs`. Test a hand-authored stroke's full-resolution pixels, preview pixels, save/reopen fidelity, undo state, and rejection of invalid or over-budget strokes. Render through the existing compositor and alpha policy. Keep schema version 2 compatible with old projects.
2. **Collection store:** Add `src/project_library.rs` with safe collection-name and path handling, local root preference, collection creation, project save, and direct-folder indexing. Test persistence across new store instances, reopening the exact project, missing roots, malformed projects, symlinks, and path traversal.
3. **Content covers:** Render each indexed project through `load_document` and `render_document` at a bounded size. Test a deliberately painted color pixel in the cover and that a corrupt project has an error instead of a false cover. Provide page size and cancellation/generation checks for UI workers.
4. **Native UI:** Add Brush and paint-layer controls, commit one undo state per drag, and show a live gesture. Add an image-first gallery with collection tabs, search, paging, create/save/reopen controls, and real empty/error states. Route project switching through the existing unsaved-change guard. Adjust contrast, spacing and hierarchy against the inspected current image and visual reference.
5. **Verification and publication:** Run Rust formatting and diff checks locally. Use a bounded public hosted Windows workflow for tests and binary artifact, then run that exact binary against synthetic local projects to capture and inspect the native editor/gallery. Document source/CI/runtime provenance, open a draft PR, and leave main unchanged.

Review focus: an old project must load; a locked layer must not paint; an interrupted gesture must not leave half a stroke; a corrupted cover must not replace current work; a stale worker result must not overwrite a newer collection selection; save into an existing project must keep its identity guard.
