# SkinStrike creator foundation decision

This is a focused comparison for the current draft, not a feature-parity claim.

| Foundation | Actual workflow and rendering | Fit for this draft | License/source impact |
| --- | --- | --- | --- |
| [SkinStrike current source](../src/document.rs) | Portable v2 project with embedded PNG assets, RGB layers, alpha controls, UV reference, bounded vector paint strokes, and a common preview/export compositor. Rust and egui 0.30. | Retain. The CS2 texture and alpha workflow, saved project identity, and existing migration are already represented. The paint slice has hosted renderer tests. Native interaction and visual quality still need verification. | Existing project notices stay in place. |
| [PhotoCraft](https://github.com/storytold/photocraft) | Rust photo editor with a much broader paint engine: brush settings, dynamics, dab rendering, tiles, and many retouch tools. Its [paint crate](https://github.com/storytold/photocraft/tree/main/crates/paint) depends on its geometry, color, and raster crates; its workspace uses eframe 0.36. | Useful architecture reference, but pulling in its engine entails adapting several crates, brush serialization, rendering surfaces, and the UI/document model. That migration is larger than this focused CS2 finish workflow and would replace working document semantics. Reassess if pressure/dynamics or advanced masks become concrete requirements. | Dual MIT/Apache-2.0 in its [repository](https://github.com/storytold/photocraft). No code or assets copied in this draft. |
| [ArmorPaint](https://github.com/armory3d/armorpaint) | GPU 3D texture painting with material nodes and model viewport, built around a C native stack. | Powerful different workflow; adopting it would be a language/runtime and product-model migration, not a small improvement to the existing 2D Rust editor. | [zlib/libpng notice](https://github.com/armory3d/armorpaint/blob/main/license.md) requires retaining its source notice and identifying altered versions if code is redistributed. No code or assets copied. |

Decision: continue the current Rust foundation on the isolated draft branch. Reuse ideas only at the interaction level, with our own code and creator-owned project content. Review the decision if the product scope shifts to full 3D material painting or expressive professional brush dynamics. The current stroke renderer is intentionally a bounded round brush, not an equivalent of either larger application.
